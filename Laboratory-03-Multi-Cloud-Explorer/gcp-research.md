| Category       | GCP Service                           | Purpose                                     |
 
 Computing       **Compute Engine**                     Runs virtual machines                       
 Storage         **Cloud Storage**                      Stores files, images, videos, and backups   
 Database        **Cloud SQL**                          Managed relational databases                
 Data Analytics  **BigQuery**                           Analyzes very large amounts of data         
 Containers      **Google Kubernetes Engine (GKE)**     Runs and manages containerized applications 
 Serverless      **Cloud Run**                          Runs applications without managing servers  
 AI/ML           **Gemini / Google Cloud AI services**  Develops and uses AI applications           
 Networking      **Virtual Private Cloud (VPC)**        Connects and protects cloud resources
